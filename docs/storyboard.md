# Homepage motion storyboard

Design decision: use a continuous workflow map, rather than a day/night landscape. Its changing state explains the Fractional FDE service directly.

| Chapter | Copy focus | Workflow-map state |
| --- | --- | --- |
| Start | AI that gets into the work | Inbox, spreadsheet, and CRM appear as separate, quiet nodes |
| Discover | Find where work gets stuck | The route between existing tools begins to emerge |
| Connect | Connect tools; preserve the process | One active path links the tools through the workflow |
| Review | AI drafts; the client decides what ships | A person and approval mark replace the abstract center node |
| Improve | Stay useful after go-live | A feedback loop returns the workflow to ongoing refinement |
| Plans | Choose the support level | The completed map remains steady behind the plans |
| Questions | Clarify boundaries before starting | The reviewed, improving system remains as the final state |

The visitor uses ordinary scrolling, with gentle chapter snapping and a numbered chapter rail. Do not capture or reinterpret wheel input. On narrow screens use proximity snapping, reduce scene opacity behind text, and preserve a natural vertical read. Under reduced-motion preferences, keep the final visual states but remove transitions and moving signal dots.
